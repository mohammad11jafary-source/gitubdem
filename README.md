- نام و نام خانوادگی: [اسم خودت رو بنویس]
- عنوان ارائه: ساخت Pipeline با GitHub Actions شامل build، test و lint

## توضیح
این پروژه یک نمونه ساده پایتون است که با GitHub Actions به‌صورت خودکار lint، test و build می‌شود.

## نحوه اجرا
- نصب وابستگی‌ها: pip install -r requirements.txt
- اجرای تست: pytest
- اجرای lint: flake8 app.py test_app.py

## مشاهده Pipeline
به تب Actions در GitHub بروید و آخرین اجرا را ببینید.
